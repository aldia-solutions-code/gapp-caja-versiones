# GAPP Nube Caja — instaladores

Aquí se publican **solo los instaladores** de GAPP Nube Caja para Windows, en
[Releases](../../releases). No hay código fuente en este repositorio.

- Cada instalador va acompañado de su firma (`.sig`). Las cajas verifican esa firma con la llave
  pública que traen incluida y **no instalan nada que no esté firmado** por Al Día Paraíso.
- Las cajas se actualizan solas cuando nadie las está usando. No hace falta descargar nada a mano,
  salvo para la primera instalación o para reinstalar una caja.
